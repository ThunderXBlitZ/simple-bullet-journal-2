# User Stories

## Daily Logging
- As a user, I want to add tasks, events, and notes with traditional bullet notation (•, ○, —) so I can capture information quickly.
- As a user, I want to cycle task status (open → complete → migrated → scheduled → irrelevant) by clicking the bullet so I can track progress.
- As a user, I want to indent entries (0-3 levels) using Tab/Shift+Tab so I can organize subtasks hierarchically.
- As a user, I want to edit entry text inline by clicking it so I can correct mistakes without recreating entries.
- As a user, I want to delete entries with a trash icon (hover-reveal) so I can remove unwanted items.
- As a user, I want to migrate incomplete tasks from past days to today so I can track carried-over work.

## Calendar Views
- As a user, I want a weekly view with 7 day cards showing entries and quick add so I can see my week at a glance.
- As a user, I want a monthly calendar view with task progress indicators so I can visualize patterns over time.
- As a user, I want to navigate between weeks/months easily so I can plan and reflect on different time periods.

## Habit Tracking
- As a user, I want to create habits with custom icons and colors so I can track personal goals.
- As a user, I want to toggle habit completion in a monthly grid view so I can see my consistency at a glance.
- As a user, I want to see my completion percentage for each habit so I can measure adherence.
- As a user, I want to see a streak counter so I can stay motivated by consecutive days.
- As a user, I want to delete habits so I can remove ones I no longer track.

## Collections (Custom Lists)
- As a user, I want to create custom collections (e.g., Books, Movies, Goals) so I can maintain various lists.
- As a user, I want to add items with checkboxes to collections so I can track progress on multiple lists.
- As a user, I want to see completion percentage and item count for collections so I can gauge progress.
- As a user, I want to toggle item completion and delete items so I can manage list contents.

## Search & Navigation
- As a user, I want to open the Command Palette (Cmd/Ctrl+K) so I can quickly navigate and search.
- As a user, I want to search all entries by keyword so I can find past content.
- As a user, I want to jump directly to any date's daily log from search results so I can access relevant information.
- As a user, I want to navigate between views (Daily, Weekly, Monthly, Habits, Collections) from the command palette so I can switch views quickly.

## Backup & Sync
- As a user, I want to export my journal as JSON and import a backup back in so I can move or recover data.
- As a user, I want to sign in with Google and sync this journal across devices so I don't lose it.
- As a user, I want merges to preserve records from both devices and propagate deletes so my devices converge.
- As a user, I want a clear sync status and a reconnect prompt so I know when sync is paused.

## Settings & Customization
- As a user, I want to toggle Focus Mode (hides sidebar/nav) so I can work distraction-free.
- As a user, I want to toggle between Light and Dark themes so I can choose my preferred aesthetic.
- As a user, I want visual options (show decorative dots, show lines) so I can customize the journal look.
- As a user, I want all changes to persist in IndexedDB so I don't lose data between sessions.

## Responsive & Mobile
- As a mobile user, I want a fixed bottom navigation bar so I can switch views without scrolling the page.
- As a mobile user, I want only the entry list to scroll so the header stays visible.
- As a mobile user, I want optimized text sizes and button spacing so the interface is touch-friendly.
